# Spec - NMD Page Surface

This document specifies the `.nmd` page-file surface inside the datasource
Markdown workspace realization. It builds on [requirements.md](./requirements.md).

The `.nmd` page surface is realized by the composition of
`@overeng/notion-md` and `@overeng/notion-datasource-sync`.

Standalone NotionMD details remain in
`packages/@overeng/notion-md/docs/vrs/`.
