# Requirements - NMD Page Surface

## Context

These requirements refine the datasource Markdown workspace realization for the
visible `.nmd` page-file surface.

## Requirements

### Must remain portable NotionMD

- **NSA.REAL.DMW.NMD-R01 refines: NSA-R06:** Page files in datasource
  workspaces must remain valid standalone NotionMD `.nmd` files.
- **NSA.REAL.DMW.NMD-R02 refines: NSA-R07:** `.nmd` property and body writes
  must be judged by workspace evidence, not by file presence alone.
