# NMD Page Surface Intuition

*For: NotionMD and datasource-sync maintainers · Assumes: datasource Markdown
workspace realization · Covers: visible `.nmd` files inside a workspace*

This child node isolates the public `.nmd` page surface inside datasource
workspaces.

The page file must remain a valid NotionMD file, but datasource workspace sync
adds authority, schema, and settlement expectations that standalone NotionMD
does not need by itself.
