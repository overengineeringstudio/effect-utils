# Genie Projection Requirements

**Role:** This subsystem defines how Genie projects the parent
[semantic graph](../requirements.md) into reviewable Buck inputs. It does not
own semantic package facts, dependency closures, Buck rule behavior, or build
tool selection.

## Context

Genie is a projection adapter. Its output is committed, read-only configuration
whose freshness is checked locally and in CI. The normalized semantic graph is
its complete semantic input.

## Assumptions

- **BUCK.GRAPH.GENIE-A01 Parent graph:** Inputs satisfy the strict,
  runtime-neutral semantic graph contract.
- **BUCK.GRAPH.GENIE-A02 Genie lifecycle:** Discovery, read-only output modes,
  and repository freshness reporting satisfy Genie's root VRS.

## Acceptable Tradeoffs

- **BUCK.GRAPH.GENIE-T01 Generated configuration:** Package-local Buck
  configuration may be committed generated output when this makes review and
  cold Buck analysis deterministic.

## Requirements

### Must remain a pure projection

- **BUCK.GRAPH.GENIE-R01 Data-only input:** Projection must consume normalized
  semantic graph values and declared renderer configuration only. It must not
  reconstruct semantic facts from generated package, project, or test files.
- **BUCK.GRAPH.GENIE-R02 No build execution:** Projection must not invoke a
  compiler, bundler, type checker, test runner, package builder, Buck action, or
  compiler dependency-analysis mode.
- **BUCK.GRAPH.GENIE-R03 No tool identity semantics:** Concrete Bun, `tsgo`,
  Rust, Cargo, Nix store, or platform identities must not affect semantic shard
  bytes.

### Must emit stable local projections

- **BUCK.GRAPH.GENIE-R04 Package-local shards:** Each package must receive a
  package-local generated shard derived from that package's normalized model
  and stable shared schema only.
- **BUCK.GRAPH.GENIE-R05 Deterministic bytes:** Equal normalized input must emit
  byte-identical output regardless of authored set ordering or equivalent
  renderer implementation.
- **BUCK.GRAPH.GENIE-R06 Unrelated-shard stability:** A change confined to one
  package must leave every unrelated package shard byte-identical.
- **BUCK.GRAPH.GENIE-R07 Thin semantic surface:** Generated shards must express
  semantic target declarations through a stable Buck facade. They must not
  inline action commands, toolchain paths, or duplicated rule implementations.

### Must make freshness and provenance truthful

- **BUCK.GRAPH.GENIE-R08 Authoritative freshness:** One supported Genie check
  must regenerate and compare all semantic graph projections and fail on
  missing, stale, writable, or conflicting outputs.
- **BUCK.GRAPH.GENIE-R09 Non-semantic provenance:** Operational provenance may
  identify an authored source, schema version, and regeneration command, but a
  generator or tool implementation change that preserves output semantics must
  not churn semantic shard bytes.
- **BUCK.GRAPH.GENIE-R10 Completeness separation:** Source-file completeness
  validation must enforce the parent graph contract without compiling sources
  or forcing matched file enumeration into generated bytes. Genie validates and
  renders typed file-set declarations; Buck observes matching membership and
  the independent census validates total, non-ambiguous ownership.
- **BUCK.GRAPH.GENIE-R11 Causal projection tests:** Tests must prove stable
  ordering, equivalent-renderer bytes, unrelated-shard stability, package move
  behavior, target split locality, and refusal of compile/process capabilities.
- **BUCK.GRAPH.GENIE-R12 Composed dependency facet:** Genie package composition
  must preserve exact typed dependency references in non-emitted metadata before
  manifest maps widen. Projection modules must consume that facet through a
  one-way, side-effect-free import graph; generated or rendered output is not an
  authority for reconstructing it.
