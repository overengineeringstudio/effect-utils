# Buck2 Pin 2026-08-22 Compatibility Replay

Date: 2026-08-27 — Host: dev3 (x86_64-linux) — target release
`2026-08-22` (`c89474de8970db1d3784063e2fb1efb1803bb177`).

## Question

After the completed Phase-1 authority transfer, can effect-utils advance from
nixpkgs Buck2 `2026-04-15` to the immutable upstream `2026-08-22` release
without broad nixpkgs lock churn or breaking the admitted graph, cache,
materialization, and product-bridge surfaces?

## Method

A repo-local `nix/buck2.nix` package authority uses `pkgs.buck2.overrideAttrs`
to retain nixpkgs' native-binary behavior while replacing only the release
assets and compatible Prelude passthru. Both flake and devenv consume that
package without duplicating release metadata. Nix prefetched, rather than
guessed, the Buck2 and rust-project assets
for x86_64-linux, aarch64-linux, and aarch64-darwin plus Prelude revision
`b662bc5f374762afc05e7033d6a0f8d4da462d45`. Unsupported x86_64-darwin
remained fail-closed.

Validation covered:

1. Nix parse/evaluation for all three admitted systems and the unsupported
   x86_64-darwin negative;
2. x86_64-linux derivation build/install check and exact `buck2 --version`;
3. capability projection check + invalidation test;
4. `buck2:check` provider/toolchain analysis surface;
5. tui-core node_modules, package_tree, typecheck, and dist targets;
6. directory `:dist --out` materialization and action/provider queries;
7. cache-disabled local execution;
8. fleet-cache upload, daemon/buck-out wipe, and cache read;
9. strict TypeScript and repository quick gates on the integrated worktree.

## Result

- Exact binary version:
  `buck2 2026-08-22-c89474de8970db1d3784063e2fb1efb1803bb177`.
- All three admitted platform derivations evaluated; x86_64-darwin evaluation
  failed at the explicit unsupported-system boundary.
- Capability projection, `buck2:check`, all four tui-core labels, directory
  `--out`, and aquery/provider analysis passed unchanged.
- Cache-disabled execution passed. After daemon and generated-state wipe, the
  fleet-configured populate/read control for the all-four-label tui-core closure
  reported five cache hits and no execution:
  `Commands: 5 (cached: 5, remote: 0, local: 0)`.
- A later 2026-08-27 verification established that `buck2:check` executes zero
  actions. This replay therefore establishes provider/toolchain analysis
  compatibility, not real-work execution by that task.
- All Buck daemons were stopped. One narrow `nix/buck2.nix` package authority
  supplies both the flake output and devenv; flake and devenv locks did not move.

## Conclusion

The immutable upstream 2026-08-22 release is compatible with the admitted
standalone effect-utils surface. The narrow override fulfills decision 0012's
post-Phase-1 pin intent without coupling the change to unrelated nixpkgs
packages. Subsequent experiments use this pin; the older dated records remain
valid observations of their stated binaries.

## VRS Impact

Discharges decision 0012 item 7 and the roadmap's deferred pin-bump item. No
requirement or action-contract change. Composition and foreign-host admission
still require their normal exact-platform revalidation when those phases run.
