01

Overview

~30-min recorded showcase

A ~30-minute recorded showcase of in-house Notion developer tooling, pitched at a developer / power-user audience. The framing for every tool is the same arc: gap (what Notion doesn't give you) → stopgap (what the tool does today) → what first-class would look like.

notion md→ notion sqlite→ notion schema / IaC→ notion-react (stretch) + HTML-block-from-API bonus

Per-tool structure: a full-screen explainer (gap/stopgap framing, diagram, table) followed by a live demo against the real packaged CLI.

Pacing decided: ~3-min punchy demos each. The md takeaway is live two-way propagation — guarded-merge lands as the payoff.

02

Demo pool

4 demos — all BUILT + TESTED vs real packaged CLIs

notion md

Built · Tested

Watch-mode hero. Local Markdown ⇄ Notion, guarded so neither side clobbers.

notion md sync --watch roadmap.nmd spec.nmd

Edit + save → Notion updates live. Reverse pull from Notion. Diverged both sides → guarded-merge conflict roughdraft, never an overwrite.

notion sqlite

Built · Tested

Edit a Notion database as local SQLite.

notion db

Guarded sync with a fail-closed gate: if the remote diverged, the write is refused rather than silently applied.

notion schema / IaC

Built · Tested

Introspect a Notion DB → typed schemas → drift gate.

notion schema generate -o schema.gen.ts notion schema generate-config notion schema diff --exit-code

Honest scope: introspect → codegen → drift detection, not provisioning. diff --exit-code is the drift gate.

notion-react

Built · Tested

JSX → reconciler → block ops. Render a page from a component tree.

bun run page.tsx

Diff-only reconcile: an unchanged re-run reports updates:1 — it touches only what changed.

+ Bonus beat — HTML block from the API. Upload a file and embed it as a live HTML block: ntn files create → embed.file_upload. Each explainer page carries one of these live HTML blocks.
