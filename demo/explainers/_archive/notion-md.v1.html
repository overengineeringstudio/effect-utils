Notion tooling · primitive 01

notion md — local Markdown ⇄ Notion, safely

Keep a folder of Markdown in two-way sync with Notion pages, with a guarded merge that never clobbers.

The gap

Notion's API is great, but there's no first-class way to keep local Markdown in sync with pages. You hand-roll API calls or copy-paste — and either side can silently overwrite the other.

The stopgap

An .nmd file is the source of truth. sync does a 3-way merge against a local object store; a diverged remote yields a *.conflict.roughdraft.md instead of an overwrite.

What first-class would look like: Notion offering native Markdown-file binding with conflict-aware sync — until then, notion md fills the gap.
