# Vision — Notion Tooling Demo

A ~30-minute recorded showcase of the in-house Notion developer tooling, for
**developer / power-user Notion users** who already know the Notion
API/CLI/Workers and want to build more advanced things on Notion.

The through-line is **gap → stopgap → what first-class would look like**: for
each tool we make a real platform gap felt, show the pragmatic tool built to
fill it, and name what native Notion support would eventually look like. These
tools are honest stopgaps, not claims that Notion is inadequate — the audience
hits the same walls, so the framing lands as peer-to-peer.

Two audiences share one set of artifacts: the recorded video, and a set of
problem-first visual **explainer threads** (one per tool) that also stand alone
as X threads.

The demo must be **repeatable and provable** — every beat is driven live from a
fresh, isolated environment, and every claim is backed by an end-to-end harness,
not hope.
