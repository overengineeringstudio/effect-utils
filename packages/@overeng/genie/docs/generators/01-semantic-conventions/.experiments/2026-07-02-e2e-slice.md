## New fidelity delta (weaver 0.24.2 vs 0.23)

- **Every enum member requires `stability`** in 0.24.2 (0.23 did not) — a real delta the
  earlier feasibility experiment missed. The Layer-2 `attr.enum` now defaults each member's
  stability from the attribute's stability.

## Settled mechanism shapes (→ spec)

- **`requirement_level` (registry) vs Schema optionality (encoder)** are two axes: a wrapper
  API (`required`→non-optional; `recommended`/`conditionally`/`optIn`→optional) maps both
  cleanly and reads better than a parallel map.
- **weaver annotation** rides a SEPARATE `WeaverAttrAnnotationId` symbol (does NOT pollute
  otel-contract's `OtelAttrMetadata`), carrying `weaverType` EXPLICITLY (AST type-inference is
  fragile for literals/templates/brands; optionally cross-check vs AST).
- **YAML** MUST use a real encoder (the `yaml` package); the hand-built-string path is retired
  (SC-R05).
- **Upstream ref-integrity**: aggregation checks first-party + cross-member integrity and
  DEFERS upstream refs to weaver (the authoritative resolver); upstream resolvers declare
  `providesNamespaces`.
